C5GG05P0Dépose - repose : Garnissage de coffre
1. Dépose
Basculer la banquette vers l’avant.
Déposer :
  • Le dossier de banquette (voir opération correspondante)
  • La ceinture ventrale arrière (voir opération correspondante)
1.1. Véhicules avec chargeur C.D
Figure : c5gp00ec
Déconnecter le faisceau électrique (1).
Déposer :
  • Les pions plastique (2)
  • Le garnissage du boîtier (3)
Figure : c5gp00fc
Déposer :
  • Les 3 vis (4)
  • Les 3 vis (5)
  • Le chargeur
Figure : c5gp00gc
Déposer :
  • Les 4 vis (6) de fixation du boîtier
  • Le boîtier

2. Repose
Procéder dans l’ordre inverse des opérations de dépose.
