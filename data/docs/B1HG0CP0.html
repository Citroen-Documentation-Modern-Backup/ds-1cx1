B1HG0CP0Dépose - repose : Injecteurs , Moteur XU5JP
SYSTEME INJECTION MAGNETI MARELLI
IMPERATIF : Il faut déposer la rampe d’injection avant de déposer un injecteur. Le non-respect de cette condition entraînerait un blocage hydraulique du moteur, suite au remplissage des cylindres, par le carburant se trouvant dans la rampe d’injection.
1. Dépose
Figure : b1hp02dc
Déposer le tuyau d’air.
Désaccoupler :
  • Les durits (1), (3) et (4)
  • Le câble d’accélérateur
  • Les tuyaux d’essence
Figure : b1hp02ec
Déconnecter :
  • Les injecteurs
  • Les connecteurs (5), (6), (7) et (8)
Désaccoupler les durits (12) sous le boîtier papillon.
Déposer :
  • Les écrous
  • La vis
  • Le guide-fil
Figure : b1hp003c
Déposer :
  • Les 6 vis (13)
  • La rampe d’injection
Vider la rampe d’injection.
Déposer :
  • Les vis
  • Les plaquettes
  • Les injecteurs
2. Repose
Figure : b1hp003c
Poser :
  • Les injecteurs
  • Les plaquettes
  • Les vis (14) Serrer à 0,8 m.daN
  • La rampe d’injection
  • Les 6 vis (13) Serrer à 1,9 m.daN
Figure : b1hp02ec
Poser :
  • Le guide-fil
  • Les écrous
  • La vis
Accoupler :
  • Les durits (12) sous le boîtier papillon
  • Les tuyaux d’essence
  • Le câble d’accélérateur
Connecter :
  • Les injecteurs
  • Les connecteurs (5), (6), (7) et (8)
Figure : b1hp02fc
Reposer le tuyau d’air.
Accoupler les durits (1), (3), (4) et (17).
Purger le circuit de refroidissement (voir opération correspondante).
