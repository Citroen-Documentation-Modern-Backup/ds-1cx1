B1HT03P0Évolution : Pompe d’injection mécanique avec blindage métallique pour l’antidémarrage codé
1. Préambule
Démarrage progressif de nouvelles pompes d’injection mécanique BOSCH équipée d’un module antidémarrage codé avec blindage métallique (année modèle 1997).
2. Présentation
Figure : b1hp0hvd
A Ancienne disposition :
  • (1) Module ADC (capotage plastique)
  • (2) Vis à têtes autocassables
B Nouvelle disposition :
  • (3) Blindage métallique
  • (4) Vis à têtes autocassables
3. Ancienne disposition
Le module ADC est fixé sur la pompe d’injection par 2 vis à tête autocassable (2).
4. Nouvelle disposition
4.1. Particularités
La nouvelle pompe d’injection ne diffère de la précédente que par un blindage métallique ( 3) fixé par 5 vis à tête autocassable (4).
Le blindage métallique ( 3) recouvre le module ADC (1).
NOTA : Les caractéristiques de réglages ainsi que la connectique de pompe d’injection n’ont pas évolués.
4.2. Identification
Il y a 2 possibilités d’identification :
  • Identification visuelle
  • Identification par la référence
Identification visuelle.
Le blindage métallique ( 3) de couleur noir recouvre l’électrovanne d’arrêt de pompe d’injection mécanique.
Identification par la référence.
Exemple
Type véhicule CITROËN XANTIA
Type moteur XUD9BTF/Y/L3
Référence inscrite sur la pompe d’injection (avec module ADC et blindage métallique) VE4/9F2250 R601 - 2
5. Réparation
5.1. Diagnostic
ATTENTION : Avant toute dépose d’une pièce du système antidémarrage codé, il est nécessaire d’effectuer des contrôles à l’aide de l’outil de diagnostic boîtier ELIT + OUT 4173-T.
5.2. Interchangeabilité
Le nouveau blindage métallique ( 3) ne peut pas être installé sur une pompe d’injection "ancienne disposition".
Le module ADC et l’électrovanne d’arrêt de pompe sont identiques pour les deux montages.
Le Service des Pièces de Rechange commercialise les deux types de montage.
5.3. Intervention sur le module ADC et l’électrovanne d’arrêt de pompe
ATTENTION : La conception du blindage métallique ( 3) interdit toute dépose de celui-ci. Toute intervention sur le module ADC et l’électrovanne d’arrêt de pompe est impossible. Il est nécessaire de déposer la pompe d’injection et de faire réaliser l’intervention par un agent BOSCH.
6. Dépose de la pompe d’injection
6.1. 1er cas : Verrouillage et déverrouillage du module possible
ATTENTION : Avant dépose de la pompe, le module doit être déverrouillé.
ATTENTION : Noter le code utilisateur sur la pompe et non pas le code service.
NOTA : Seul le code utilisateur est connu du module . Le code service est connu par le clavier ADC.
Procédure de déverrouillage :
  • Mettre le contact
  • Déverrouiller le module en composant le code utilisateur (code composé au clavier ADC)
  • Ne pas couper le contact
  • Débrancher le connecteur reliant le module au faisceau moteur (l’électrovanne d’arrêt n’est alors plus alimentée) : (4 voies noir)
  • Couper le contact
  • Écrire le code utilisateur sur la pompe
Cette procédure :
  • Permet de s’assurer que le module est effectivement déverrouillé
  • Est la seule autorisant un contrôle de pompe au banc (sans échange de module)
Contrôle de pompe au banc.
Module déverrouillé, le fonctionnement de la pompe est possible après avoir alimenté l’électrovanne par le connecteur fixé sur la pompe (4 voies noir) :
  • Voie 1 --> +12V
  • Voie 4 --> Masse
6.2. 2ème cas : Verrouillage et déverrouillage du module impossible
Pour permettre l’analyse des défauts, effectuer les opérations suivantes :
  • Écrire le code utilisateur sur la pompe
  • Noter le résultat de l’analyse effectuée avec l’outil de diagnostic
