B3BG0BP0Dépose - repose : Capteur d’accélération, Suspension hydractive
SUSPENSION HYDRACTIVE
Le capteur d’accélération est placé sur le support de pédale d’accélérateur.
1. Dépose
Figure : b3bp02wc
Déposer :
  • La garniture inférieure
  • Les écrous de fixation du support (2)
Figure : b3bp02xc
Le connecteur (3) est situé sous la planche de bord. Il peut être enrubanné dans une mousse.
Figure : b3bp02yc
Couper le collier plastique (4) de maintien du faisceau électrique.
Figure : b3bp02zc
Débrancher le connecteur . Utiliser un miroir.
2. Repose
Rebrancher le connecteur .
Graisser l’articulation.
Reposer le support de pédale.
Le doigt du capteur doit être au-dessus de la pédale.
Remplacer le collier plastique.
Reposer la garniture inférieure (1).
