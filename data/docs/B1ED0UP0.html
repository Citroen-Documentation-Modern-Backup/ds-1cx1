Déposer le couvercle du boîtier calculateurs ( 5).
Figure : b1ep08rc
Déconnecter les calculateurs ( 6) et (7).
Dégrafer les relais ( 8).
Déposer :
  • Le boîtier calculateurs ( 9)
  • Le support moteur droit (4)
  • Les carters de distribution (3)
  • La poulie de vilebrequin

  • Les carters de distribution (3)
  • La courroie d’accessoires (voir opération correspondante)
