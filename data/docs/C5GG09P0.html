C5GG09P0Dépose - repose : Garnissage de coffre
1. Dépose
Basculer l’assise et le dossier de la banquette arrière, vers l’avant.
Figure : c5gp01hc
Déposer :
  • Le snappon ( 3) d’entrée de coffre (partiellement)
  • La garniture centrale d’entrée de coffre (vis (1); (2))
Figure : c5gp01jc
Déposer vis (5).
Dégrafer le montant d’entrée de coffre ( 4).
Figure : c5gp01kc
Dégrafer les garnitures d’encadrement de custode ( 6).
Figure : c5gp01lc
Déposer le couvercle (7) (coffre de passage de roue).
Figure : c5gp01mc
Déposer :
  • Les vis (8)
  • Les écrous (9)
Déposer le garnissage de coffre (10).
Figure : c5gp01nc
Déposer :
  • Le support de tablette arrière (vis (11))
  • Le brin de boucle de ceinture de sécurité (vis (12))
  • L’enrouleur ceinture de sécurité (13)
  • Le verrouillage du dossier arrière (vis (14))
  • La vis (15)
Figure : c5gp01pc
Déposer :
  • Le joint snappon d’entrée de porte ( 17) (partiellement)
  • La ceinture de sécurité arrière (18)
  • Les vis (16) et (19)
  • La garniture avant du garnissage de coffre
2. Repose
Procéder dans l’ordre inverse des opérations de dépose.
