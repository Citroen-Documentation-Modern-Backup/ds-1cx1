Desserrer le frein de parking.
Déposer les roues avant.

  • Les biellettes de passage de vitesses (4)
  • La rotule d’échappement (3)
Déposer :
  • La sonde lambda  (voir opération correspondante)
  • Le pot catalytique
Figure : b3fp014c

  • Les rivets
  • L’écran thermique

Déposer :
  • La vis
  • La barre de commande de vitesses
  • L’écran thermique (11)
  • Les 4 rondelles à dents (7)
  • L’écran thermique
Figure : b3fp016c
Désaccoupler les câbles secondaires (12) du palonnier (voir opération correspondante).
NOTA : Il n’est pas nécessaire, lors de cette opération, de dégager les câbles secondaires (12) des guides câbles.
Figure : b3fp017c
Déposer la console centrale  (voir opération correspondante).
Désaccoupler : Le câble primaire (14).
Figure : b3fp018c

  • Les écrous (15)

  • Les écrous (17)
  • Le palonnier (13) et le câble primaire (14)
2. Repose
Figure : b3fp019c
Poser :
  • Le palonnier (13) et le câble primaire (14)
  • Les écrous (17)
  • La patte
Vérifier l’état du joint d’étanchéité situé sous la patte.
Poser les écrous (15).
Enduire de graisse G6 les points "a".
Figure : b3fp017c
Accoupler : Le câble primaire (14).
Poser la console centrale (voir opération correspondante).
Figure : b3fp016c
Accoupler les câbles secondaires (12) sur le palonnier (voir opération correspondante).
Figure : b3fp00xc
Accrocher : L’embout de câble (2). Enduire de graisse G6.
NOTA : Après avoir préréglé le frein de stationnement, tasser et positionner les gaines de frein, en manoeuvrant 10 fois le levier de frein de stationnement avec un effort de 40 daN.
Effectuer le réglage du frein de stationnement (voir opération correspondante).
Serrer l’écrou (1) à 3 m.daN.

Figure : b3fp014c
Fixer l’écran thermique (6) à l’aide de rivet POP ALU (5) Ø4 L 16mm.
