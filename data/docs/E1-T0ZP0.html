4. Antidémarrage codé (ADC)
Nouveau clavier "ADC" (voir note tous types "ADC") :
  • Apparition de la touche S : Mode service
  • Disparition de la touche D /N ou --
Mode service : Permet de confier le véhicule à une tierce personne tout en gardant la confidentialité du code utilisateur.
Le clavier "ADC"possède un autodiagnostic, relié à la prise diagnostic.
Procédure d’utilisation , Mode service :
  • Mettre le contact
  • Introduire le code de l’utilisateur (code à 4 chiffres)
  • Appuyer sur la touche S : Bip sonore (1)
  • Introduire le code service (code à 4 chiffres)
  • Appuyer sur la touche S : La LED verte clignote 6 fois avec 6 bips sonores (2)
  • Couper le contact : La LED rouge reste allumée accompagnée de 4 bips sonores (pendant 10 secondes) (3)
Annulation du mode service :
  • Mettre le contact
  • Introduire le code de l’utilisateur
NOTA : (1).
Pas de bip sonore :
  • Le mode service n’est pas autorisé
  • Pour passer en mode service, le code utilisateur doit avoir été utilisé au moins 2 fois
  • Fermer le véhicule
  • Recommencer la procédure
NOTA : (2).
Bip sonore long :
  • Le mode service n’est pas autorisé
  • Introduire le code C 0 C La LED verte clignote 4 fois avec 4 bips sonores
  • Couper le contact
  • Recommencer la procédure
NOTA : (3) Se produit à chaque coupure du contact tant que le mode service est activé.
