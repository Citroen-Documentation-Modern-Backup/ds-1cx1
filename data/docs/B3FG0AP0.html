B3FG0AP0Dépose - repose : Plaquettes de frein arrière
1. Dépose
Débloquer les vis de roues.
Lever et caler le véhicule, roues arrière pendantes.
Déposer les roues.
Figure : b3fp006c
Déposer :
  • L’écrou
  • La tôle
Figure : b3fp007c
Déposer :
  • L’axe
  • Le ressort
  • Les plaquettes de frein
Nettoyer l’extrémité des pistons à l’essence.
Déposer quelques gouttes de LHM sur les pistons.
Poser :
  • Les anciennes plaquettes de frein
  • L’axe
Appuyer en "a" pour repousser les pistons à fond dans leur logement.
Déposer :
  • L’axe
  • Les plaquettes de frein
Nettoyer le logement des plaquettes.
2. Repose
Reposer :
  • Les plaquettes de frein
  • Le ressort
ATTENTION : Respecter le sens de montage du ressort .
Reposer :
  • L’axe
  • L’écrou
  • La tôle
Serrer l’écrou .
Reposer les roues.
Remettre le véhicule sur ses roues.
Serrer les vis de roues .
