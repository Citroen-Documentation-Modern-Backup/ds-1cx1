B1HG03P0Dépose - repose : Injecteurs moteur XU7JP
IMPERATIF : Il faut déposer la rampe d’injection avant de déposer un injecteur. Le non-respect de cette condition entraînerait un blocage hydraulique du moteur, suite au remplissage des cylindres, par le carburant se trouvant dans la rampe d’injection.
1. Dépose
Figure : b1hp001c
Déposer le tuyau d’air.
Désaccoupler :
  • Les durits (1), (3) et (4)
  • Le câble d’accélérateur
  • Les tuyaux d’essence
Figure : b1hp002c
Déconnecter :
  • Les injecteurs
  • Les connecteurs (5), (11) et (12)
Désaccoupler les durits (10) sous le papillon des gaz.
Dégrafer les durits (10) de la patte du papillon des gaz.
Débrancher le tube .
Déposer :
  • Les écrous
  • La vis
  • Le guide-fil
Figure : b1hp003c
Déposer :
  • Les 6 vis (13)
  • La rampe d’injection
Vider la rampe d’injection.
Déposer :
  • Les vis
  • Les plaquettes
  • Les injecteurs
2. Repose
Figure : b1hp003c
Poser :
  • Les injecteurs
  • Les plaquettes
  • Les vis (14) à 0,8 m.daN
  • La rampe d’injection
  • Les 6 vis (13) à 1,9 m.daN
Figure : b1hp002c
Poser :
  • Le guide-fil
  • Les écrous
  • La vis
Agrafer les durits (10) sur la patte du papillon des gaz.
Accoupler :
  • Les durits (10) sous le papillon des gaz
  • Les tuyaux d’essence
  • Le câble d’accélérateur
  • Les durits (1) et (6)
Connecter :
  • Les injecteurs
  • Les connecteurs (5), (11) et (12)
Figure : b1hp004c
Reposer le tuyau d’air.
Accoupler les durits (3), (4), (17) et (18).
Purger le circuit de refroidissement.
